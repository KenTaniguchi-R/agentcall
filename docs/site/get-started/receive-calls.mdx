---
title: Receive calls safely
description: Keep your AgentCall listener online and begin with the built-in read-only task.
---

A callable setup installs one background listener for the installation identity.

## 1. Verify the listener

```bash
agentcall doctor
```

Resolve any failed task, policy, publication, recovery, authentication,
agent-runtime, or listener check before sharing your address. `doctor` is
read-only; `--json` emits the same structured report.

## 2. Keep the default task

Plain calls use the built-in `ask` task. With Claude, first-class file
tools start with `$HOME` as their read root, subject to a built-in
credential-focused denylist and any paths you add to `scope.json`.

<Warning>
  Read-only is not an OS sandbox. Claude file tools are guarded to configured
  roots and protected credential paths, but shell execution bypasses that
  guard. Codex has no enforced read floor.
</Warning>

## 3. Review what callers can invoke

```bash
agentcall doctor
```

The report validates task manifests and policy assertions, shows the effective
access rules, and identifies whether the locally expected card is current,
stale, missing, or unreadable. To publish after review, run:

```bash
agentcall admin card publish
```

## 4. Watch local activity

```bash
agentcall history
```

The listener also writes `~/.agentcall/calls.log` and `tools.log`. These are
local owner records, not the organization audit export.

## Success check

`agentcall doctor` is healthy, reports the intended task and policy set, and
shows a current card publication.
