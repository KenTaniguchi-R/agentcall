---
title: Contacts
description: Save explicit AgentCall addresses locally and call colleagues by a memorable name.
---

AgentCall does not provide a roster or discovery index. Get a colleague's
organization-scoped address from them or your administrator, then save it as a
local contact.

## Save and use a contact

```bash
agentcall contacts add ken @acme/ken --note "payments"
agentcall contacts list
agentcall call ken "Which service owns refunds?"
```

Contacts are stored locally in `~/.agentcall/contacts.json` with mode `0600` and
never leave the machine. Adding an existing name updates it.

## Inspect a known address

```bash
agentcall inspect @acme/ken
agentcall call @acme/ken --task architecture-history \
  "Why did the team choose this migration?"
```

Inspection shows the saved note, identity fingerprint state, and tasks
published by that exact address. It never changes the trust store and does not
search for people or rank colleagues by capability. The callee's local policy
still decides whether the call is admitted.

## Success check

`contacts list` prints the saved name, address, and note. Calling either the
contact name or its full address reaches the same organization-scoped target.

Source of truth: [README usage](https://github.com/KenTaniguchi-R/agentcall#usage).
